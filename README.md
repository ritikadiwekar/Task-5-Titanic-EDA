# 🚢 Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Titanic dataset using Python. The objective is to identify patterns, trends, and factors that influenced passenger survival.

---

## 🎯 Objectives

- Understand the structure of the dataset
- Analyze passenger demographics
- Identify factors affecting survival
- Visualize relationships between variables
- Extract meaningful insights from data

---

## 🛠️ Tools & Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

The dataset contains information about Titanic passengers, including:

- Passenger ID

## 📊 Key Findings

### 👥 Age Distribution

- Most passengers were between 20 and 40 years old.
- Very young and elderly passengers were fewer in number.

### 💰 Fare Distribution

- Ticket fares varied significantly.
- Several high-fare outliers were present.

### 👩 Survival by Gender

- Female passengers had higher survival rates.
- Male passengers had lower survival rates.

### 🎟️ Survival by Passenger Class

- First-class passengers had better chances of survival.
- Third-class passengers experienced the highest number of deaths.

### 🔥 Correlation Analysis

- Fare showed a positive relationship with survival.
- Passenger class was negatively correlated with survival.

---

## 📈 Conclusion

The Exploratory Data Analysis revealed that **Gender, Passenger Class, and Fare** were the most influential factors affecting passenger survival.

Female passengers and first-class travelers showed significantly higher survival rates. The analysis successfully identified important patterns, trends, and relationships within the dataset using statistical methods and visualizations.
